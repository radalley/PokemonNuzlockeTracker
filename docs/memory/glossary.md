# Lockley Glossary

- `game_id`: A specific game, such as Red or Blue.
- `version_group_id`: A rules/data generation grouping shared by related games.
- Run: A named Nuzlocke campaign owned by a user or guest store.
- Attempt: One playthrough attempt within a run.
- Event boss: A trainer encounter placed in a game's progression script.
- Badge award: A normalized relationship created from a defeated event boss.
- Curated memory: Concise, intentionally maintained architecture knowledge.
- Session log: Automatically captured user and assistant turns used for recall.
