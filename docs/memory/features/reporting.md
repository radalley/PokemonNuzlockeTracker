# Reporting

Users open a reusable contact panel and choose bug, missing information,
incorrect information, or general contact. Bug reports include what happened
and reproduction steps. Missing or incorrect information can target Pokemon,
trainer, or other data. Application context is submitted automatically and is
hidden from users.

Admins access `/admin/reports` from the main menu. The reports view filters by
status, game, and version; the statistics view is a sortable generation-aware
table split by report type.
